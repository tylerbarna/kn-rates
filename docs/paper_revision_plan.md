# Paper revision plan (Nov 2026)

Both manuscripts were re-drafted as **preliminary** versions (`paper/ms.tex`, `paper/companion_paper_imposters_criteria.tex`). Both compile with `latexmk -pdf`.

- Every number in the drafts comes from `snapshots/knrates_results_latest.zip` through `knrates`, or from `knrates/literature.py`.
- Values that depend on runs not yet done are written as red `\tbd{...}` placeholders.
- Every bibliography entry was checked against arXiv metadata and Crossref (DOI → journal, volume, page, year). The full list is at the end.

### 1.2 Proposed structure
1. Introduction: kilonovae, previous untargeted limits, GW BNS rate, goal.
2. ZTF data and selection criteria (compared with A20 and ZTFReST).
3. Simulation and statistics: injections, VT (Eq. 1), pooling, Poisson/FC; models (POSSIS fixed and isotropic, AT2017gfo-posterior, population; one-zone only if re-tuned).
4. Results: Table 1, Fig. 3 (limits vs literature/GW), Fig. 1 (sensitivity vs time; 23-month comparison), Fig. 4 (distance reach).
5. Viewing-angle dependence: Fig. 2.
6. Monte Carlo convergence: Fig. 5 (short; could move to an appendix).
7. **Archival candidate search** (required for an observational limit).
8. Systematics: quantified budget.
9. Discussion/conclusions: comparison with the GW rate, population-averaged limit, Rubin outlook.

### 2.2 Proposed structure
1. Introduction.
2. Method: candidate generation, criteria grid, filter, **validation against the full simulation**.
3. Results: one-at-a-time response, elasticity at the fiducial point, pairwise interactions, how the A20/ZTFReST criteria compare.
4. Contamination-aware criteria (planned; see 2.3).
5. Recommendations.

### 2.3 How the contamination results could actually be produced
`survey-sim` (commits `b3588ef`, `599501e` … `206325d`) contains an imposter framework (`src/efficiency/imposters.rs`, `KilonovaImposterAnalysis`). Its presets set imposter populations from *assumed* rates and hand-specified rejection fractions (e.g. a IIb preset with ~1.2×10³ Gpc⁻³ yr⁻¹ citing "Salafia et al. 2026", and colour-slope rejection as an input fraction). Those inputs are not simulation outputs and need verified sources before any use.

`survey-sim` also provides fiesta light-curve models for shock cooling, CSM interaction, GRB afterglows and cocoons (`python/survey_sim/fiesta_*_model.py`). A defensible contamination study would:
1. inject each imposter class through the same ZTF exposure history and Suite 02 filter, giving recovery efficiencies per grid point;
2. multiply by literature volumetric rates with uncertainties (each to be verified);
3. compare the simulated recovered imposters with the Barna+2025 catalogue as an empirical check;
4. evaluate colour-evolution cuts on the simulated multi-band photometry, which requires storing model magnitudes;
5. only then build completeness–purity frontiers and Rubin projections.

### 2.4 Placeholders
The fiducial-point validation at ≥5 grid points, the number of ensemble realisations, every Figure/Table value in §3, and the summary all depend on the **Suite 02 ensemble re-run**: `bash scripts/submit_fast_criteria_sweep.sh --ensemble --samples 100`, then the filter. Contamination numbers depend on the §2.3 simulations.
